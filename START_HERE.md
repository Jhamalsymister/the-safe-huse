## ❓ FAQ

**Q: Does it require special hardware?**
A: No! Uses Windows built-in WiFi detection and system audio.

**Q: Is it safe?**
A: Completely safe - just displays information, no data capture.

**Q: Can I receive radio broadcasts?**
A: Not with this app. This is an analyzer. To receive broadcasts, you'd need an RTL-SDR (~$25).

**Q: Does it work on Mac/Linux?**
A: Partially - WiFi detection works on Windows. Full cross-platform support in extended versions.

**Q: Can I modify the code?**
A: Yes! It's Python, completely customizable.

## 🔧 Troubleshooting

### "WiFi networks not showing"
- Make sure WiFi is on
- Press SPACE to force scan
- Wait a few seconds (updates every 10s)
- Try running as administrator first time

### "App won't start"
- Make sure Pygame is installed: `pip install pygame`
- Use correct Python version: Python 3.7+
- Check file is in the right location

### "Just showing simulation, not real data"
- That's the no-audio version (which is fine!)
- Real audio version requires PyAudio setup
- Current version demonstrates features well
